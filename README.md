# GTA 6 Clipper

This entry is an AI-agent-edited vertical Short featuring a beach-gym bench-press moment from GTA 6.

The published clip is on YouTube: [Watch the Short](https://youtube.com/shorts/Sf64p6OkhNs).

`main.ts` reads the repository's `VIDEO.json` and copies it into the configured output directory. The grader sets `MAKEFUN_BOT_DIR` and `MAKEFUN_OUTPUT_DIR` to choose those locations.
